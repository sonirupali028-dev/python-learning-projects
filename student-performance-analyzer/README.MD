# Student Performance Analyzer 

A beginner-friendly Python data analysis project that analyzes student marks, calculates statistics, categorizes performance, and visualizes results.

## Features

- Calculates average marks for Maths, Science, and English.
- Finds the highest and lowest marks in each subject.
- Calculates individual student averages.
- Identifies the top-performing student.
- Categorizes performance as Excellent, Good, or Needs Improvement.
- Filters students who need improvement.
- Saves the final report to a CSV file.
- Creates three graphs to visualize student performance.

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib

## Installation

1. Install Python.
2. Clone or download this repository.
3. Install the required libraries:

```bash
python -m pip install -r requirements.txt
```

## Run the Project


python main.py
